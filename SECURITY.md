# Security policy

MicAway changes microphone mute state and handles no audio. Please still treat security and privacy regressions seriously.

Do not open a public issue for a vulnerability that could expose private data, bypass expected mute behavior, or execute code unexpectedly. Email the maintainer privately at the address listed on the GitHub profile for `akashp1712`, with:

- the affected version or commit;
- reproduction steps;
- expected impact;
- any suggested mitigation.

Please do not include recordings, dictated text, credentials, or unrelated system logs. You should receive an acknowledgment within seven days.
